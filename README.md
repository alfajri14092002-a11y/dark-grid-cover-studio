# Dark Grid Cover Studio

A GTA 6-style cover art maker. Drop in a photo, pick a layout and a dark colour grade, write the caption, export the PNG.

Five photo panels, three layouts, four dark grades, bold lettering, PNG export in 1080 x 1080, 1080 x 1350 and 1920 x 1080. Runs offline in a desktop browser; photos never leave the machine.
